# Application de secrétariat — شركة الصداقة

Application en arabe pour créer, enregistrer et imprimer des lettres professionnelles.

## ▶️ تشغيل التطبيق | Lancer l'application

لا تحتاج إلى أي تثبيت — افتح `index.html` في المتصفح، أو شغّل خادماً محلياً:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## ✨ المزايا

- **➕ زر «إضافة نموذج جديد»** (في أعلى الصفحة، الشريط الجانبي، قسم النماذج، والمحرر):
  إنشاء نماذج خطابات قابلة لإعادة الاستخدام باسم وتصنيف وموضوع ونص خاص بك.
- نموذج جاهز كمثال: **«تسليم قيمة»** (نموذج مالي لإثبات تسليم مبلغ مع توقيع المستلم)،
  بالإضافة إلى: طلب إجازة، شهادة عمل، تعميم إداري، دعوة اجتماع.
- تعديل النماذج ونسخها وحذفها والبحث فيها وتصفيتها حسب التصنيف.
- متغيرات ذكية داخل النص مثل `{{اسم_المستلم}}` و `{{المبلغ}}` و `{{التاريخ}}`
  تتحول تلقائياً إلى حقول تعبئة عند استخدام النموذج.
- محرر خطابات مع معاينة A4 فورية، حفظ الخطابات، إعادة فتحها وتعديلها، وطباعة / تصدير PDF.
- حفظ تلقائي في متصفحك (`localStorage`) — بدون خادم أو قاعدة بيانات.

## 📊 جداول البيانات الداخلية (لمجموعة الشركات)

قسم جديد **«جداول البيانات الداخلية»** مصمم لخدمة مجمع شركات:

- **إدارة الشركات والشعارات**: أضف شركات المجموعة وارفع شعار كل شركة،
  واختر في أي جدول: ترويسة **بشركة واحدة** أو **الشركتين معاً — مجموعة الشركات**،
  مع جهة مستقلة **«المالك — سيارة خاصة»**.
- **🚗 كشف صلاحية السيارات — مجموعة الشركات والمالك** (النموذج الأبرز):
  نوع السيارة، الموديل، اللوحة، الهيكل، السائق، وانتهاء **الترخيص / التأمين / الفحص الدوري**،
  مع حالة تلقائية: 🟢 سارية — 🟡 تنتهي خلال 30 يوماً — 🔴 منتهية وتحتاج تجديداً، وتصفية حسب الشركة أو الحالة.
- نماذج جاهزة أخرى من أبرز قوالب الجداول الداخلية: صيانة ووقود السيارات،
  الحضور والانصراف، بيانات الموظفين (انتهاء العقود)، الرواتب (صافٍ تلقائي)،
  المصروفات، الأصول والجرد، حركة المخزون (رصيد تلقائي)، وسجل الصادر والوارد.
- **➕ نموذج جدول جديد**: أنشئ قالبك الخاص بكتابة أسماء الأعمدة فقط.
- كل جدول قابل للتعبئة المباشرة، والحفظ وإعادة الفتح، والطباعة الأفقية A4 بالترويسة والشعارات والتوقيعات، والتصدير إلى Excel ‏(CSV).
- **أعمدة قابلة للتعديل بالكامل** من لوحة «🧩 تعديل الأعمدة»: إعادة تسمية أي عمود،
  تغيير نوعه (نص / تاريخ صلاحية / رقم / شركة-مالك / قائمة منسدلة / محسوب)، إضافة عمود،
  نسخه، حذفه، وإعادة ترتيبه — مع زر «حفظ الأعمدة في النموذج الأصلي» لجعل التعديل دائمًا في القالب.
